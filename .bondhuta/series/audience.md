## যা ধরে নেওয়া হয়েছে (কোথাও ব্যাখ্যা করা হয়নি)

| যা ধরে নেওয়া | প্রমাণ |
|---|---|
| **Matrix কী, তা জানা আছে** | পর্ব ২: "ধরি একটা 4×1 matrix —" — কোনো ভূমিকা নেই, সরাসরি ব্যবহার |
| **Transpose আগে শেখা** | পর্ব ২: "**মনে আছে** transpose?" — শেখানো নয়, মনে করিয়ে দেওয়া। একটা এক-লাইনের রিমাইন্ডার: "দাঁড় করানো matrix-টা শুইয়ে দিলেই হলো" |
| **Matrix গুণের ফল কী দাঁড়ায়, চোখে দেখলে মেনে নেওয়া যায়** | পর্ব ২-এ 1×4 × 4×1 = 1×1 দেখানো হয়েছে, নিয়ম ব্যাখ্যা করা হয়নি |
| **অসমতা এপাশ-ওপাশ করা** | পর্ব ২: "একপাশ থেকে threshold-টা অন্যপাশে নিয়ে গেলাম, ব্যাস।" — এক বাক্যে সারা |
| **ঋণাত্মক সংখ্যা, দশমিক, শতাংশ** | পুরো পর্ব ২ জুড়ে `-3.0 + 1.20 + 0.95 + 0.60 = -0.25` কোনো টীকা ছাড়া |
| **ইংরেজি technical শব্দ পড়তে অসুবিধা নেই** | `input`, `output`, `threshold`, `weight`, `dataset`, `feature`, `scale`, `epoch`, `iteration`, `online learning`, `convergence`, `desired output` — সবই Latin script-এ, বাংলা প্রতিশব্দ ছাড়া |
| **monospace-এ সাজানো হিসাব পড়তে পারা** | পর্ব ২-এ ৯টা `code-box`, প্রতিটাতে বহু-লাইনের arithmetic |
| **subscript notation** | `x₁ w₂ w₀` কোনো ভূমিকা ছাড়াই |

## যার জন্য থেমে ব্যাখ্যা করা হয়েছে

| যা ব্যাখ্যা হয়েছে | কীভাবে |
|---|---|
| **neuron কী** | একেবারে শূন্য থেকে, ছবি সহ, মস্তিষ্কের সাথে মিলিয়ে |
| **কেন শুধু যোগ নয়, weighted sum** | মোটুকে দিয়ে ভুল উত্তরটা বলিয়ে ("তাহলে তো তিনটা যোগ করেই কাজ শেষ"), তারপর ভতুর শোধরানো |
| **`−threshold` কীভাবে `+w₀` হলো** | মোটুর "মাইনাসটা প্লাস হয়ে গেল কীভাবে? 😮" — একটা পুরো dialog exchange শুধু চিহ্নের গোলমাল সরাতে |
| **x₀ = 1 কেন দরকার** | "w₀ × 1 = w₀, কাজেই কিছু বদলায় না, শুধু দেখতে সুন্দর হয়" |
| **epoch বনাম iteration** | সরাসরি disambiguate করা হয়েছে, এমনকি প্রচলিত শিথিলতার কথাও বলা: "(অনেকে ঢিলেঢালাভাবে দুটোকে একই অর্থে বলে ফেলে, কিন্তু পরিষ্কার করে বললে এটাই নিয়ম।)" |
| **পরের student কোন weight পাবে** | মোটুর প্রশ্নে একটা আস্ত section, তারপর নাম: online learning |
| **matrix দিয়ে লেখার লাভ কী** | মোটু সরাসরি জিজ্ঞেস করে "এগুলো কেন করছি আপু?" — উত্তর পরে, `Wᵀ X` মিলে যাওয়ার মুহূর্তে |

**এই বিপরীতটাই পাঠকের ছবি আঁকে**: matrix গুণ ব্যাখ্যা লাগেনি, কিন্তু একটা
বিয়োগ-চিহ্নের যাত্রা ব্যাখ্যা লেগেছে। মানে পাঠকের গণিতের *যন্ত্র* আছে,
কিন্তু গণিতের ওই যন্ত্র কোন কাজে লাগছে সেটার *গল্প* নেই। সিরিজটা গল্পটা দেয়,
যন্ত্রটা নয়।

## যা ধরে নেওয়া হয়নি

- **Calculus** — দুই পর্বের কোথাও derivative, slope, limit — কিছু নেই।
  পর্ব ১০-এ gradient আনতে হলে derivative-এর intuition ওই পর্বেই শূন্য থেকে
  বানাতে হবে।
- **Programming** — একটাও লাইন code নেই। Python নেই, numpy নেই, কোনো library
  নেই। `code-box` শুধু হাতের হিসাব সাজাতে ব্যবহৃত।
- **Machine learning-এর কোনো পূর্বজ্ঞান** — "training" শব্দটা পর্ব ১-এর শেষে
  প্রথমবার আসে এবং সংজ্ঞায়িত হয়।
- **Statistics** — mean, variance, probability, distribution — কিছুই ব্যবহার
  হয়নি। পর্ব ১-এর "সম্ভাবনা বের করতে চাই" কথ্য অর্থে, probability-র কারিগরি
  অর্থে নয়।
- **ইংরেজিতে দীর্ঘ প্রযুক্তি-লেখা পড়ার অভ্যাস** — এই সিরিজের অস্তিত্বের কারণই
  এটা।
